# 异步编程的实现方式

## 回调函数

回调是一个最基本的异步编程方式，使用它有一个缺点：如果多个回调函数发生嵌套行为，则会造成回调函数地狱，不利于代码的维护

## [promise](./promise.md)

使用 promise 的方式可以将潜逃的回调函数作为链式调用，但多个链式调用可能会造成代码语义不明

## generator

- generator 可以在函数执行的过程中，将函数的执行权转移出去，在函数外部还可以将执行权转移回来
- 当遇到异步函数执行时，将函数执行权转移出去，当异步函数执行完毕后再将执行权转移回来
- 因此在 generator 内部对于异步操作的方式，可以用同步的顺序来书写
- 使用时最大的问题是何时将函数的控制权转移回来，所以需要一个自动执行 generator 的机制

## async 函数

async 函数是 generator 函数 + 自动执行器 实现的语法糖。当函数内部执行到一个 await 语句时，会等待异步行为执行后继续向下执行，因此可以将异步逻辑转化为同步顺序来书写。
